Platform workflow

One pipeline.
Inspectable steps.

The demo exposes the current analysis path, from food recognition through geometry and nutrition lookup. Each stage is useful for debugging; none should be mistaken for a guarantee of physical accuracy.

01 / IDENTIFY

Recognize and locate

Food recognition proposes labels; object detection locates candidate regions and segmentation extracts food masks.

02 / ESTIMATE

Geometry with limits

Monocular depth can provide relative geometric cues. Absolute metric scale from one image remains a separate, unresolved validation problem.

03 / ENRICH

Nutrition lookup

Recognized foods can be matched to FatSecret records, then scaled only when a usable mass estimate is available. Missing values must remain missing.

Scientific honesty: ActualPlate does not currently claim a validated ≤5% absolute-volume error rate. When metric scale or mass is unavailable, the product must report that limitation rather than invent a number.

Platform roadmap

Enterprise capabilities

  • Organization-scoped API keys, scopes, rotation, and revocation
  • JWT login for the developer portal; role-based access control
  • Usage metering, atomic plan limits, and shared rate limiting
  • Versioned API schemas, predictable errors, and request IDs
  • Operational health, observability, and deployment checks
  • SDKs, Postman collection, webhooks, and billing after the foundation
Trust & operational boundaries

Clear about what is ready.

Enterprise readiness is a set of verified controls—not a visual design or a checklist marked complete before implementation.

In progress

Request safety

Backend work is tightening upload validation, request-size limits, CORS policy, and safe public errors. Production deployment still needs environment-specific verification.

Not released

Identity & tenant isolation

Database-backed users, organizations, API keys, RBAC, audit logs, and customer usage records are planned foundational work—not features customers can rely on yet.

Validation gate

Metric accuracy

Model evaluation against independently measured ground truth, uncertainty reporting, and drift monitoring must precede any accuracy guarantee.
